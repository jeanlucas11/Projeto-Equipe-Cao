# SGDI - Sistema de Gestão de Demandas Internas

Sistema web para gerenciamento de demandas internas da empresa, permitindo controle, priorização e acompanhamento das solicitações.

---

## 🚀 Como rodar o projeto

```bash
python init_db.py
python app.py
```

Acesse no navegador:
http://localhost:8000

---

## 📌 Funcionalidades

* Criar demandas
* Editar demandas
* Deletar demandas
* Visualizar detalhes
* Adicionar comentários
* Filtrar demandas por prioridade (múltiplo)
* Ordenar demandas por prioridade

---

## 🧠 Tecnologias utilizadas

* Python
* Flask
* SQLite
* HTML + Jinja2
